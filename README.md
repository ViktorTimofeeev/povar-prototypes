# Прототипы «Мой повар»

Опубликованные кликабельные прототипы. Исходники живут в рабочем репозитории,
сюда выкладываются только готовые файлы.

- `kartochki/` — карточки блюд и время приготовления, два варианта.
- `zakrytie-grafika/` — график работы повара: пауза при 7 и больше выходных подряд.
- `glavnaya-pro-povarov/` — главная про поваров: шесть вариантов первого экрана.
- `glavnaya-koncepty/` — главная: два концепта из Figma, повар с рядом блюд и портрет повара.
- `glavnaya-ryad-povara/` — главная: концепт с рядами поваров и видео в баннере (Figma 4609:38495).
